# /friends/add

Use a token generated by [/friends/generate](friends-generate.md) to add that
person as a friend directly.

- URL: `https://api.getfriend.ly/friends/add`
- Method: `POST`
- Headers:
    - `Content-Type: application/json`
    - `X-User-Id: $userId`
    - `X-Token: $token`

## Request Body

```typescript
{
    "userId": number,
    "token": string
}
```

- `userId`
    - The `id` of the target
- `token`
    - The token from their [/friends/generate](friends-generate.md) call

## 401 Not Authorized

If provided authorization is invalid.

## 200 Success

```typescript
{
    "type": "FriendTokenExpired" | "Success"
}
```

- `Success`
    - You are now friends with `userId`
- `FriendTokenExpired`
    - The token was already used or is no longer valid.

## Example

```bash
curl https://api.getfriend.ly/friends/add \
    --request POST \
    --header "Content-Type: application/json" \
    --header "X-User-Id: $userId" \
    --header "X-Token: $token" \
    --data '{
        "userId": 123,
        "token": "..."
    }'
```
